# 📱 [Hydrogram]


**Hydrogram** - это учебный клон мессенджера Telegram для Android. Проект создан с целью глубокого изучения внутренней архитектуры современных систем обмена сообщениями, работы с real-time данными и облачными хранилищами объектов.


**Главная цель** — погрузиться во «внутренний мир» мессенджеров и решить сложные инженерные задачи, с которыми ежедневно сталкиваются разработчики крупных платформ: организация real-time UI, оптимизация передачи тяжелого медиаконтента и построение отказоустойчивой архитектуры.

## ✨ Ключевые фичи
* 🔐 **Безопасная авторизация** — аутентификация пользователей по номеру телефона и email через *Firebase Auth*.
* 💬 **Real-time обмен сообщениями** — мгновенная доставка сообщений без необходимости обновлять экраны вручную.
* 🟢 **Онлайн** — отслеживание и отображение текущего статуса пользователей в реальном времени через *Realtime Database*.
* 🎙 **Мультимедиа сообщения** — полноценная поддержка записи и отправки аудио- и видеосообщений («кружков»).
* ☁️ **Облачное хранилище контента** — вынос тяжелых медиафайлов в объектное хранилище *Yandex Cloud (S3)*, что значительно снижает нагрузку на основную базу данных. Медиафайлы загружаются в Yandex Object Storage через S3-совместимый API, а в базе данных хранятся ссылки и метаданные файлов.
* 🔔 **Push-уведомления** — оперативное информирование о новых сообщениях в фоновом режиме через *Firebase Cloud Messaging (FCM)*.



## 🌐 Инфраструктура и сервисы
| Компонент                      | Назначение                                        |
| ------------------------------ | ------------------------------------------------- |
| Firebase Authentication        | Регистрация и вход пользователей                  |
| Firebase Realtime Database     | Онлайн-статусы и обмен данными в реальном времени |
| Yandex Object Storage          | Хранение аудио, видео и других медиафайлов      |
| Firebase Cloud Messaging (FCM) | Push-уведомления о новых сообщениях               |


## 🛠 Технологический стек & Архитектура

Приложение написано строго по современным стандартам Android-разработки:

* **Язык**: Kotlin 2.0.21
* **UI**: Jetpack Compose
* **Архитектура**: Clean Architecture + MVVM.
* **Асинхронность**: Kotlin Coroutines & Flow
* **Внедрение зависимостей**: Hilt
* **Сеть и Backend**:
  `Firebase` для хранения структурированных данных пользователей и сессий,
  `Yandex Cloud (S3)` для надежного хранения и быстрой раздачи медиа файлов

## 🏗 Архитектура

Проект использует Clean Architecture и MVVM.

- **Presentation** — Jetpack Compose, ViewModel и UI state.
- **Domain** — бизнес-логика, модели и Use Cases.
- **Data** — репозитории, источники данных, сетевые запросы и DTO.

Зависимости между слоями организованы так, чтобы
бизнес-логика не зависела от конкретных источников данных.

```text
com.example.hydrogram/
├── data/
│   ├── di/
│   ├── dto/
│   ├── repository/
│   ├── service/
│   ├── util/
│   └── wrapper/
├── domain/
│   ├── model/
│   ├── repository/
│   └── usecase/
└── presentation/
    ├── navigation/
    ├── screens/
    ├── states/
    ├── util/
    ├── viewModel/
    └── widgets/
        └── messages/
```
