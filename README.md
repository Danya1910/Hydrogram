# 📱 [Hydrogram]

Hydrogram - это учебный клон мессенджера Telegram для Android. Проект создан с целью глубокого изучения внутренней архитектуры современных систем обмена сообщениями, работы с real-time данными и облачными хранилищами объектов.


**Главная цель** — погрузиться во «внутренний мир» мессенджеров и решить сложные инженерные задачи, с которыми ежедневно сталкиваются разработчики крупных платформ: организация real-time UI, оптимизация передачи тяжелого медиаконтента и построение отказоустойчивой архитектуры.

Ключевые фичи:
* **Безопасная авторизация** - аутентификация пользователей по номеру телефона, email через Firebase Auth
* **Real-time** обмен сообщениями - мгновенная доставка сообщений без необходимости обновлять экраны вручную
* **Онлайн** - отслеживание онлайна пользователей Realtime Database
* **Мультимедиа сообщения** - полноценная поддержка записи и отправки аудио и видеосообщений (кружков)
* **Облачное хранилище контента** - вынос тяжелых медиафайлов в объектное хранилище Yandex Cloud (S3), что снижает нагрузку на основную базу данных
* **Push-уведомления** - оперативное информирование о новых сообщениях в фоновом режиме через Firebase Cloud Messaging (FCM)
-

Технологический стек:
* **Язык**: Kotlin 2.0.21
* **UI**: Jetpack Compose
* **Архитектура**: Clean Architecture + MVVM. Четкое разделение на слои (`Data` -> `Domain` -> `Presentation`) для тестируемости и масштабируемости кода
* **Асинхронность**: Kotlin Coroutines & Flow
* **Внедрение зависимостей**: Hilt
* **Сеть и Backend**:
  `Retrofit 2` для REST API запросов 
  `Firebase` для хранения структурированных данных пользователей и сессий,
  `Yandex Cloud (S3)` для надежного хранения и быстрой раздачи медиа файлов
